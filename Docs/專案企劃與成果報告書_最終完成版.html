## 壹、 專案主題發想與核心願景

### 一、 專案研發背景與動機
在物聯網（IoT）與智慧家庭普及的今日，多數微型感測器僅被單純用於數據回傳或定點監控，使用情境過於單一，當使用者處於休閒或工作狀態時，昂貴的硬體設備往往處於低利用率的閒置狀態。另一方面，市售商業體感遊戲設備（如 VR 手把、方向盤、動態捕捉儀）動輒數千至數萬元，且通訊協議封閉，一般學生或獨立創作者難以客製化開發。

為打破硬體壁壘，本專案由林安均、卓立凱團隊發起，打造**《多功能智慧安全監測與虛實互動體感系統》**。透過 Arduino UNO 開發板，串接超音波、三軸加速度計、溫濕度感測器、雙軸搖桿與 OLED 螢幕，建構具備「環境哨兵」與「體感控制器」雙重靈魂的創新型智慧互動物聯網系統。

### 二、 核心雙模價值定位：平時為安全哨兵，戰時為體感手把
本系統最大的創新亮點在於**「一套感測硬體，賦予雙重生命」**：
1. **常態模式：桌上型微型智慧安全與環境監測站（Security Sentry Mode）**
   - 放置於書桌或玄關，HC-SR04 超音波持續掃描前方警戒距離，防範背後人員突襲；ADXL345 偵測地震微震與防偷竊搬動；DHT11 掌握室內溫濕度，透過 0.96 吋 OLED 螢幕即時可視化輪播。
2. **遊戲模式：跨平台 3D 體感極速跑酷控制器（Kinetic Controller Mode）**
   - 當使用者啟動電腦端的 Unity 6 遊戲《極速躍動 3D》（Rolling Leap 3D）時，透過 Serial 序列埠以 20Hz 採樣率將實體數據打包串流：
     - **超音波推進跳躍**：使用者手持裝置向前猛然一推，距離瞬間驟減即判定為「強力躍動推進」！
     - **三軸重心傾角操控**：手持控制板左右傾斜操控賽道走位，前推衝刺、後拉煞車，模擬重力平衡球。
     - **類比搖桿 360° 環繞視野**：以右拇指撥動搖桿，無死角旋轉鏡頭仰視 500 米摩天天梯！

### 三、 實際應用場景
- **個人工作站 / 遊戲電競桌**：平時在桌面上充當賽博龐克風格的溫濕度時鐘與防背後突襲雷達；工作疲勞時一鍵切入 Unity 跑酷挑戰，享受實體體感紓壓。
- **居家玄關 / 臥房門口**：作為人員進出警示哨兵，亦可當作智慧門禁與環境狀態儀表。
- **創客與互動技術教學展演**：展示如何以極低成本的 Arduino 感測器，經由數學濾波與通訊協定，打造手感媲美商用控制器的 Unity 虛實整合案例。

### 二、 序列埠串流通訊協定 (Serial Stream Protocol)
為確保數據在高頻傳輸時不丟包、不造成 Unity 主渲染執行緒卡頓，團隊制定了精簡而高效的單向 ASCII 序列埠協定：
- **傳輸速率**：`9600 Baud Rate`（每秒約 960 字元，佔用極低單晶片資源）。
- **更新頻率**：`20 FPS`（週期 `50ms`，兼顧反應即時性與感測器轉換時間）。
- **封包結構**：
  $$\text{D:<float>|AX:<float>|AY:<float>|AZ:<float>|JX:<int>|JY:<int>|B:<0/1>}\backslash\text{n}$$
- **欄位定義**：
  - `D`：超音波量測距離（單位：$\text{cm}$，範圍 $2.0 \sim 400.0$）。
  - `AX, AY, AZ`：三軸加速度向量分量（單位：$\text{m/s}^2$ 或正規化 $\text{g}$ 值）。
  - `JX, JY`：雙軸搖桿類比電壓值（$0 \sim 1023$，中心靜止值約 $512$）。
  - `B`：實體搖桿按鍵狀態（$0$ 為放開，$1$ 為按下）。
- **防禦性容錯機制**：Unity 端 `ArduinoReceiver.cs` 採用獨立非阻塞執行緒進行緩衝區讀取，遇封包殘缺或校驗失敗時自動捨棄當前幀，並保留前一幀穩定姿態，絕不拋出未處理例外導致遊戲崩潰。

### 三、 感測器訊號處理與核心演算法
#### 1. 超音波推進跳躍辨識演算法 (Push-Gesture Jump Detection)
傳統體感跳躍多半依賴按鍵，失去真實體感樂趣。本專案研發「微分距離位移率特徵辨識」：
- 設定距離時間窗 $\Delta t = 100\text{ms}$，計算手掌或機體朝螢幕前推之瞬間位移差 $\Delta D = D_{t} - D_{t-\Delta t}$。
- 當測得 $\Delta D < -15.0\text{cm}$（前推距離急劇縮短），且當前距離位於有效推進區間（$10\text{cm} \le D_t \le 45\text{cm}$）時，判定為玩家施展「猛力前推跳躍」手勢！
- 觸發後啟動 $0.4$ 秒防重彈跳冷卻時間（Cooldown Timer），防止回手時誤觸跳躍。

#### 2. 三軸傾角低通濾波與靜止阻尼強煞車 (Tilt Low-pass Filter & Deadzone Braking)
人手持握控制器必然伴隨微幅肌肉顫動與雜訊。為消除小球「帕金森式微晃」，設計兩段式訊號處理：
- **一階指數平滑低通濾波**：
  $$\bar{A}_t = \alpha \cdot A_t + (1 - \alpha) \cdot \bar{A}_{t-1} \quad (\alpha = 0.25)$$
- **靜止死區與主動煞車阻尼（v0.9.8 最新升級）**：
  當 $|\bar{A}_x| < 0.08$ 且 $|\bar{A}_y| < 0.08$ 時，系統判定玩家意圖「原地平穩停留」，Unity 物理層即刻注入主動角阻尼與線阻尼（$\text{Rigidbody.velocity} \times 0.75$），使小球能極致平穩停在狹窄天梯平台上，徹底解決球體自主滑落的挫折感。

#### 3. 雙軸搖桿死區濾波與視角動態映射 (Joystick Deadzone & Orbit Mapping)
類比搖桿存在彈簧回中誤差（常態散佈於 $500 \sim 525$）。透過自適應死區映射公式：
$$\text{Input}_{\text{norm}} = \text{Sign}(V - 512) \times \max\left(0, \frac{|V - 512| - \text{DeadZone}}{512 - \text{DeadZone}}\right) \quad (\text{DeadZone} = 40)$$
確保搖桿回中時視角完全靜止無飄移，推至極限時平滑輸出全速旋轉。

## 肆、 《極速躍動 3D》虛實整合遊戲核心設計 (v0.9.8)

### 一、 3D 物理小球運動學與雙模控制
遊戲建構於 Unity 6 物理管線之上，打造極速節奏與沉浸操控：
- **雙模無縫切換**：
  - **鍵盤/滑鼠模式**：`W/S/A/D` 控制走位、`Space` 跳躍、滑鼠自由環繞視角，適合一般電腦玩家。
  - **Arduino 體感模式**：三軸傾角直覺控制重力滾動、超音波手勢推進躍動、搖桿環繞視角，帶來無可取代的實體硬體反饋。
- **相機水平朝向向量聯動 (Camera Forward/Right)**：
  小球的運動方向並非固定世界座標，而是動態投影至相機目前的水平視野向量（$\vec{V}_{\text{forward}} = \text{Normalize}(\vec{C}_{\text{forward}} \times \vec{Up} \times \vec{Up})$）。玩家視角環繞轉向哪裡，前傾即朝向該視野衝刺，極度符合人體工學！

### 二、 四大遊戲模式全景解析
1. **10 大手作漸進特色關卡 (10 Handcrafted Levels)**：
   - 由 LV.1「霓虹大道」一路晉升至 LV.10「終極躍動」，巧妙結合高速衝刺加速帶、高空大拋物線跳躍墊、移動尖刺與極限鋼索窄道。
2. **⚡ 無盡極限跑酷模式 (Endless Mode)**：
   - 採用程序化無縫動態區塊生成算法，隨存活里程提高滾動速度與障礙複雜度，挑戰全球最高分排行榜。
3. **🛠️ 自訂場地編輯器 (Track Builder Mode)**：
   - 提供上帝俯視視角的即時網格編輯器，玩家可隨意拖放賽道板塊、彈跳墊、八面體水晶與障礙，支援 JSON 本地存檔與一鍵即時試玩驗證！
4. **🏰 500 米極限攀爬：通天天梯模式 (Sky Tower Mode - Only Up 風格)**：
   - 考驗玩家極致專注力的 500 米垂直通天天塔，全塔精雕細琢六大分區：
     - `0m ~ 80m`：【地表基座與入門階梯】寬廣平台基礎練習。
     - `80m ~ 160m`：【機械起重與鋼骨鷹架】考驗極限微操的狹窄工字鋼道。
     - `160m ~ 260m`：【微風浮島與動態跳躍】週期性橫移與垂直升降浮動島嶼。
     - `260m ~ 360m`：【空中花園與曲折圓柱】弧形階梯與旋轉機關。
     - `360m ~ 440m`：【暴風雷雲與消失板】視線受限的高空盲跳考驗。
     - `440m ~ 500m`：【天頂星環與通天終點星門】登頂踏入金色星門解鎖最終勝利榮耀！

### 三、 v0.9.8 最新版本突破與修復亮點
本專案於 2026 年 11 月 1 日正式推出 **v0.9.8 重大更新版**，全面攻克前期測試的所有體驗瓶頸：
1. 🌬️ **關卡動態微風擾動與體感互斥系統 (Dynamic Crosswind & Mutex)**：
   - 1~10 關左右微風擾動強度依難度線性遞增（Level 1 基準值 `2.4f` 至 Level 10 達到 `4.38f`），為跑酷注入動態變數。
   - **體感安全互斥**：純鍵盤模式啟用虛擬微風；**當偵測到連接 Arduino 陀螺儀時，系統自動關閉虛擬微風**，確保實體重力傾角回饋 100% 純粹直覺。
2. 🏰 **通天天梯彈跳墊烈焰金橙視覺重構 (Blazing Gold-Orange JumpPad)**：
   - 徹底捨棄原先容易在高空藍天背景中「保護色隱形」的淡青外觀，重構為：高飽和度亮金橙板面、黑曜石立體深色底座、中央 45° 旋轉發光白金標誌，並賦予動態呼吸自發光脈衝，攀爬視野極度醒目！
   - 修復三個連排彈跳墊引發異常超高累加跳躍的物理缺陷。
3. 📐 **垂直空間重疊消除與寶石動態刷新防線**：
   - 重構生成間距演算法，徹底根絕上下板塊高度重疊卡球問題。
   - 動態統計活躍寶石與累計收集數，徹底修復天梯結算左上角寶石數量倒掛（如 8/7）之邏輯 Bug。
4. 🖱️ **游標全螢幕鎖定與沉浸式無界視角**：
   - 進入關卡自動鎖定並隱藏游標（`CursorLockMode.Locked`），徹底根絕多螢幕滑鼠滑出視窗外失焦的痛點；按下 `ESC` 或死亡結算時自動釋放游標。

## 陸、 專案成果、創新亮點與遭遇挑戰解決

### 一、 專案整體成果展示
1. **實體硬體終端**：完成模組化 Arduino 體感控制器，具備 OLED 狀態顯示、超音波測距前推跳躍、三軸傾角姿態感測與雙軸視角旋轉搖桿。
2. **軟體遊戲成品**：完成《極速躍動 3D》（Rolling Leap 3D）v0.9.8，內建 10 大手作關卡、無盡跑酷、賽道編輯器與 500 米通天天梯。
3. **開源專案與免安裝發布**：所有原始碼均已託管於 GitHub，並附帶已編譯通過、免安裝解壓即玩的 Windows 執行壓縮包（`54.22 MB`）。

### 二、 核心技術創新亮點
- **雙模式智慧切換（Dual-Mode Versatility）**：徹底顛覆物聯網感測器只作數據看板的缺點，平常守護居家安全，休閒時秒變極速體感搖桿。
- **超音波推進手勢演算法（Kinetic Push Algorithm）**：捨棄機械按鈕，以真實雙手往前猛推的空間位移率觸發跳躍，創造極高遊玩沉浸感。
- **智慧虛實互斥保護（Kinetic-Wind Mutex）**：一般鍵盤玩家享有動態微風挑戰，體感玩家則由系統自動卸載虛擬風阻，確保實體重力感測反饋純粹穩定。
- **專業級游標與相機鎖定體系**：徹底根絕 Unity 獨立視窗遊戲多螢幕滑鼠溢出失焦的宿疾，具備 360 度無上限環繞旋轉與死區平滑過濾。

### 三、 開發痛點、除錯歷程與解決對策

| 遭遇技術挑戰 / 缺陷 | 根本原因剖析 (Root Cause) | 最終工程解決方案 |
| :--- | :--- | :--- |
| **1. 體感手抖導致小球無法停在原地** | 人手微幅震顫使 ADXL345 輸出細小加速度，物理剛體持續受力滑落。 | 導入動態靜態死區與主動煞車阻尼，水平狀態強制注入速度衰減（$\times 0.75$）。 |
| **2. 高空背景下彈跳墊極難看清** | 原淡青色彈跳墊與高空藍天白雲高度同色，玩家難以及時預判落點。 | 視覺全面重構為「烈焰金橙板面 + 黑曜石底座 + 白金核心 + 呼吸光脈衝」。 |
| **3. 三個連排彈跳墊引發異常超高彈跳** | 剛體連續觸發 `OnTriggerEnter`，衝量多次瞬時疊加致使小球飛出天際。 | 加入 `0.35s` 彈跳衝量冷卻計時器，限制連續觸發時的垂直速度上限。 |
| **4. 天梯上下板塊重疊卡球** | 隨機階梯生成算法在垂直高度遞增與水平迴轉時未考慮物體邊界盒 (Bounding Box)。 | 重構生成間距演算法，強制限制相鄰板塊之水平與垂直安全間距 $\ge 1.8\text{m}$。 |
| **5. 寶石計數倒掛 (顯示 8/7)** | 關卡重置與動態生成時未及時重新統計場景活躍寶石，導致基數不合。 | 開發 `RefreshTotalGems()` 動態統計活躍物件 + 收集數，徹底根絕倒掛。 |
